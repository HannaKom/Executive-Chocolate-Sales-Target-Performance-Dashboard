

# 🍫 Executive Chocolate Sales & Target Performance Dashboard | Simply Modern Dark

> Управлінський дашборд рівня C-level, створений у Power BI для моніторингу фінансових показників, ефективності брендів, регіональної та місячної динаміки продажів у мінімалістичному стилі UI/UX.

---

## 📂 Джерело даних (Data Source)

* **Платформа:** Kaggle
* **Датасет:** Chocolate Sales Dataset 2023 - 2024 
* **Опис:** Сирі дані містять інформацію про транзакції продажу шоколадної продукції, продуктові лінійки, вміст какао, географію покупців та часові мітки.

---

## 🎯 Проєкт та Бізнес-задача

Створити високопродуктивний, інтуїтивно зрозумілий та естетичний дашборд для топ-менеджменту кондитерської компанії. Головна мета — забезпечити миттєвий доступ до ключових фінансових метрик (виручка, валовий прибуток, маржинальність), виявити лідерів серед брендів та категорій, а також проаналізувати виконання цілей без зайвого візуального захаращення («даних-сміття»).

---

## 🎨 Архітектура та Інтерфейс (UI/UX)

* **Концепція теми:** "Simply Modern Dark" (глибокий темний фон `#1E222D`), оптимізований для executive-презентацій .
* **Чиста ієрархія:** Акцент на верхній блок із загальними KPI-картками для миттєвого зчитування ключового стану бізнесу.
* **Сучасна фільтрація:** Інтерактивний **зріз вмісту какао (`%`)**, оформлений у вигляді стильних горизонтальних плиткових кнопок (5 в рядок) для швидкого вибору продуктової лінійки.
* **Оптимізована сітка візуалів:** Використання горизонтальних барчартів для категорій та географії (країн), що забезпечує природне читання зверху вниз та усуває зайвий когнітивний шум.
* **Продуманий дизайн таблиць:** Застосування градієнтних міні-барів (Conditional Formatting) у матриці брендів для миттєвої ідентифікації лідерів за прибутком без зайвого навантаження цифрами.

---

## 📊 Моделювання даних та Аналітика

* **Зіркова схема (Star Schema):** Побудована надійна модель із перевіреними зв'язками `1:*` між таблицею фактів `sales` та вимірами (`products`, `geography`).
* **Цілісність даних:** Повністю усунуто аномалії та нерозподілені дані (ліквідовано появу порожніх рядків `(Blank)` через аудит зв'язків).
* **Чисті DAX-міри:** Використання оптимізованих агрегаційних мір для точного розрахунку виручки, валового прибутку та відсотка маржинальності (`% Profit Margin`).
* **Логіка сортування:** Усі елементи та таблиці відсортовані за спаданням продуктивності для фокусування уваги на ключових результатах.

## ⚡ Продуктивність (Performance Analyzer)

Дашборд оптимізовано згідно з кращими практиками Power BI. Перевірка через **Аналізатор ефективності (Performance Analyzer)** показала еталонні результати завантаження візуалів (усі елементи відпрацьовують у діапазоні **250–630 мс**, що забезпечує миттєву реакцію інтерфейсу для користувача).
